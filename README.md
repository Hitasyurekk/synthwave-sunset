# synthwave-sunset

"The Star Fisher": a small figure sits on the horn of a crescent moon and fishes a fallen star out
of a night sea, while a giant whale with a constellation on its side drifts through the sky. Drawn
from code: a per-pixel sky, aurora and sea, then shapes as signed distance fields with anti-aliasing.
Python standard library only. Entered in make.fun's [coolest-art-01](https://make.fun/bounty/coolest-art-01) bounty.

(The first version was a synthwave sunset, hence the repository's name.)

```sh
ENTRY_OUT=entry.png python3 main.py
```

The same bytes every run. MIT licensed.
