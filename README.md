# synthwave-sunset

A synthwave sunset over a neon grid, computed per pixel: striped sun with glow, two ridge lines with
neon rims, a perspective grid with exact screen-space line widths, stars, scanlines and vignette.
Python standard library only. Entered in make.fun's [coolest-art-01](https://make.fun/bounty/coolest-art-01) bounty.

```sh
ENTRY_OUT=entry.png python3 main.py
```

The same bytes every run. MIT licensed.
